## 👋 About Me

안녕하세요, **함께 아이디어를 내고 맡은 일은 끝까지 책임지는 개발자 지석영**입니다.

React와 Spring Boot로 서비스를 만들고, AWS에 올려 직접 운영하며 고쳐 왔습니다. 배우와 제작사를 잇는 캐스팅 플랫폼 **[Castar](https://www.castar.co.kr)** 는 현재 **가입자 620명**이 쓰고 있고, 저는 프론트엔드, 데이터베이스 이전, 서버 배포 환경, 카카오 로그인 설계를 맡았습니다.

- 🤝 **협업과 소통** · **팀 프로젝트 5건**(2~4인)을 끝까지 마쳤고, 매주 회의로 기능과 구조를 함께 정했습니다. 그 결과 **수상 3건**(장려상·인기상·우수상)을 팀과 함께 받았습니다.
- 💡 **아이디어** · Wecand에서 카테고리 선택형 카드 구조를 제안해 **우수상**으로 이어졌고, Castar 카카오 로그인은 계정 병합 규칙 **6가지**로 설계해 **테스트 251개를 통과**했습니다.
- ⚡ **업무 효율화** · 인턴에서 **7명**이 차례로 쓰던 일일보고를 동시에 작성하는 웹 서비스로 바꿔, 대기 시간을 **85% 이상 줄였고**(이론 계산값), 근태 조회 속도는 **15초에서 3초대**로 줄였습니다. 인턴 **약 9주**에 **332커밋**(일일보고 약 241커밋)을 남겼습니다.
- 🛡 **책임감** · **가입자 620명** 서비스의 MySQL→PostgreSQL 이전, 서버 설정, 배포를 맡았고, 인턴 후반 **5주**는 개발을 전담했습니다.
