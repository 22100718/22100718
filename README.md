## 👋 About Me

안녕하세요, **함께 아이디어를 내고 맡은 일은 끝까지 책임지는 개발자 지석영**입니다.

React와 Spring Boot로 서비스를 만들고, AWS에 올려 직접 운영하며 고쳐 왔습니다. 배우와 제작사를 잇는 캐스팅 플랫폼 **[Castar](https://www.castar.co.kr)** 는 지금 **가입자 620명**이 쓰고 있고, 저는 프론트엔드, 데이터베이스 이전, 서버 배포 환경, 로그인 설계를 맡았습니다.

혼자 빨리 만드는 것보다 **팀이 같은 방향으로 가도록 이야기하고, 정한 일은 끝까지 마무리하는 것**을 중요하게 생각합니다. 매주 회의에서 기획과 구조를 함께 정했고, 그 자리에서 나온 제안이 실제 설계가 되도록 정리하는 일을 좋아합니다.
