### 🎬 Castar · 배우·제작사 캐스팅 플랫폼
> 2026.03 ~ 운영 중 · 가입자 620명(2026.10.29 기준) · 캡스톤디자인1 인기상

- 프론트엔드 약 40%(약 110커밋)를 맡았습니다.
- 백엔드 초기 구조를 만들고 MySQL에서 Supabase PostgreSQL로 이전했습니다.
- EC2, Nginx, Route53 설정으로 배포 환경을 구성했습니다.
- 카카오 로그인을 제안하고 6가지 규칙(자동 병합 금지, 인증된 이메일만 수용 등)으로 설계했습니다.

`React 19` `Spring Boot 3` `PostgreSQL` `AWS` `Nginx` `Vercel`

[프론트엔드](https://github.com/majink/castar_FE) · [백엔드](https://github.com/majink/castar_BE)
